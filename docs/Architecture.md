# Architecture

`WardogsRadio.Core` owns configuration, the canonical Music Library (`MediaSource`, reusable `LibrarySong` cues, and ordered `StationPlaylistEntry` references), Stations, Macros, transition math, the independently testable virtual playback timeline, and the pure Clip Guard / Output Health state machine. Playback receives materialized runtime song projections from those references; it does not own a second persistent cue authority. `Playback` owns provider contracts, MPV JSON IPC, endpoint meters and YouTube URL normalization. `Voicemeeter` is the only project that loads the Remote API DLL. `Input` owns controller discovery, including HID capabilities and XInput paths. `Diagnostics` consumes those abstractions and produces exportable observations. The WPF app is the composition root and presentation layer.

Output Health receives real Voicemeeter strip/B1 meter samples in the app at 10 Hz. Its runtime protection gain is composed only into WARDOGS' independent game-music player/feed and never persists or rewrites user sliders. An explicit opt-in limiter lease can set the documented selected-strip `Strip[i].Limit` parameter only after a readback-verified capability check; the app restores its prior value when released or at clean shutdown. See [Output Health](OutputHealth.md).

The virtual timeline uses an injected clock, a stored deterministic sequence, per-video duration cache, and a cursor. It projects elapsed time across cached tracks, wraps only when loop is set, flags unknown metadata instead of inventing a position, and can be paused/resumed/navigated while inactive.

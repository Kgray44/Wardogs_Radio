# Diagnostics

The Diagnostics page reports application configuration access, Voicemeeter Remote API discovery, provider paths, XInput controllers, Music Library source/song/reference integrity, Clip Guard / Output Health state, and each Station's actual configured state. Clip Guard diagnostics include the selected mode and thresholds, current B1 state, runtime game-music reduction, whether an independent protection path exists, and recent in-memory events. The Voicemeeter limiter check reads the selected music strip without changing it; when enabled, the app view also records whether WARDOGS holds a verified, reversible limiter lease. The page labels unavailable integrations rather than manufacturing pass values. Reports exclude credentials, browser data, cookies, audio samples, and unrelated files.

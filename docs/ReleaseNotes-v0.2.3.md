# WARDOGS Radio v0.2.3

## Fixes

- The installer now includes a pinned, hash-verified portable MPV build. A new
  installation can play local music and internet-radio sources without asking
  the user to install MPV separately.

## Upgrade notes

Install v0.2.3 normally through the Launcher or the WARDOGS Radio installer.
The installer keeps WARDOGS Radio settings in `%LOCALAPPDATA%\WARDOGS Radio`
and does not alter an existing system-wide MPV, Voicemeeter, or WebView2
installation.

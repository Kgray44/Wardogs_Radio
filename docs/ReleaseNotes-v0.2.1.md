# WARDOGS Radio v0.2.1

A focused usability update for the Music Library, Dashboard playlist, and persistent Now Playing surface.

## Highlights

- Add compatible Music Library songs directly to the active Dashboard playlist from its empty-space context menu or the new `+` menu beside Shuffle.
- Reworked the Music Library into cleaner source and song workspaces: independent sorting, clearer counts, multi-selection, and footer actions instead of repeated per-card buttons.
- Increased the Add Library Source window height so YouTube source fields and actions remain visible without manual resizing.
- Made mouse-wheel scrolling slower throughout app pages, library lists, dialogs, popups, and menus for precise navigation.
- Strengthened the existing Now Playing equalizer response without changing its compact dock size or layout.

## Macro controls

Macros include independent Headset Master Level and Game Master Level actions, plus matching restore actions. A Hold macro can lower either music path while a control is pressed and restore its previous level on release.

## Upgrade notes

No migration is required. Existing profiles, sources, songs, playlists, and macros remain in `%LOCALAPPDATA%\WARDOGS Radio`.

## Known limitations

Live Voicemeeter telemetry confirms the local WARDOGS Radio path but cannot prove that an external game accepted the B1 mix. SoundCloud and Apple Music remain dependent on owner-managed official authorization.

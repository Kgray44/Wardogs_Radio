# WARDOGS Radio v0.2.4

## Setup

- The installer detects the Microsoft Edge WebView2 Runtime and Voicemeeter
  Banana/Potato. If either is missing, a prerequisite page offers the official
  bundled installer and explains what feature will remain unavailable if it is
  skipped.
- WebView2 installs silently when selected. Voicemeeter Banana opens VB-Audio's
  elevated installer because it installs a virtual audio driver; restart Windows
  after it completes before configuring audio routing.
- The WARDOGS Radio uninstaller never removes either shared dependency.

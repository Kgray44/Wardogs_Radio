# WARDOGS Radio v0.2.2

## Fixes

- Fixed automatic updates from v0.2.0 and v0.2.1. The launcher now closes the downloaded installer file before verifying and moving it into the verified update location; this prevents a Windows file-lock error that previously caused the launcher to reopen the installed version instead.

## Upgrade notes

Open WARDOGS Radio through its Launcher shortcut. The Launcher will download, verify, install, health-check, and then start v0.2.2 automatically. Existing profiles and media configuration remain in `%LOCALAPPDATA%\WARDOGS Radio`.

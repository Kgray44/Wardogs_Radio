# WARDOGS Radio v0.1.0

The first stable WARDOGS Radio release delivers configurable radio-style stations, local and online playback concepts, editable macros and keyboard/controller bindings, Voicemeeter-aware routing and setup guidance, diagnostics, and protected local configuration.

This version adds the production Windows launcher, which checks official stable releases, validates the update manifest and installer SHA-256, and safely starts the installed application when updates are unavailable. The per-user installer preserves WARDOGS Radio settings and does not install or alter Voicemeeter, mpv, WebView2, or account-based provider setup.

SoundCloud and Apple Music remain setup-dependent integrations; they are not represented as ready without owner-managed authorization.
